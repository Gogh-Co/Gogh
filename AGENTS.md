# Agent notes

## Project memory

Before touching code, read `memory/STATUS.md` (current state, work in progress or
uncommitted) and the index in `memory/decisions/` (architecture decisions already
made, with their rationale — don't reopen one without the user's explicit
confirmation). When you accept a non-obvious architecture decision, add a new ADR
there; when the project's state changes meaningfully, update `memory/STATUS.md`.
